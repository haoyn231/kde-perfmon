# kde-perfmon v1.0.1

在 v1.0.0 的基础上补齐进程操作：进程行可展开查看完整命令，并提供终止与强制终止。交互与安全限制参考 DankMaterialShell 的进程上下文菜单。

This release adds process actions on top of v1.0.0: expandable rows, graceful termination and force kill, with the same guards DMS uses.

## 更新内容 / What's Changed

- 点击进程行展开或折叠，展开后显示完整命令行、PPID、内存占比 / Click a process row to expand it and show the full command, PPID and memory percentage
- 行内提供 `Terminate`（SIGTERM）与 `Force kill`（SIGKILL）/ Inline `Terminate` (SIGTERM) and `Force kill` (SIGKILL) actions
- 危险操作前需要行内确认，取消不会发送信号 / Destructive actions require an inline confirmation; cancelling sends nothing
- `SIGKILL` 只允许 PID > 1000，`SIGTERM` 拒绝 PID ≤ 1 / `SIGKILL` is limited to PIDs above 1000; `SIGTERM` refuses PIDs ≤ 1
- 信号失败时把 `errno` 文本显示在展开行里 / Failed signals surface the system error text inline
- 展开状态在每秒刷新的 model reset 后保持 / Expansion survives the one-second model reset
- 预览工具新增展开、确认与 QTest 点击回归 / The preview harness can expand rows, drive confirmations and simulate clicks with QTest

## 安装教程（KDE Plasma 6）

### 环境要求

- KDE Plasma 6（Qt 6.5+）
- Kirigami（Plasma 自带）
- 本版本在 Arch Linux / Plasma 6.8 / Qt 6.12 上构建

### 从 Release 安装（推荐）

1. 下载本页附件中的 `kde-perfmon-v1.0.1.tar.gz` 与 `kde-perfmon-v1.0.1.tar.gz.sha256`。
2. 校验并解压到当前用户的 Plasma 小程序目录：
   ```bash
   sha256sum -c kde-perfmon-v1.0.1.tar.gz.sha256
   mkdir -p ~/.local/share/plasma/plasmoids
   tar -xzf kde-perfmon-v1.0.1.tar.gz -C ~/.local/share/plasma/plasmoids
   ```
   解压后应存在：
   ```
   ~/.local/share/plasma/plasmoids/org.hao.perfmon/metadata.json
   ~/.local/share/plasma/plasmoids/org.hao.perfmon/contents/lib/Hao/PerfMon/libperfmonplugin.so
   ```
3. 让 Plasma 重新加载插件：
   ```bash
   systemctl --user restart plasma-plasmashell.service
   ```
   也可以注销后重新登录。
4. 右键面板 → **进入编辑模式**（或「添加小组件」）→ 搜索 **性能监视器** / **Performance Monitor** → 拖到面板。
5. 点击面板里的 CPU 或内存百分比打开进程列表；点击任意进程行即可展开并执行终止操作。

### 从 v1.0.0 升级

直接解压覆盖即可，面板上的小组件配置会保留；随后重启 plasmashell 使新的 QML 与插件生效。

```bash
tar -xzf kde-perfmon-v1.0.1.tar.gz -C ~/.local/share/plasma/plasmoids
systemctl --user restart plasma-plasmashell.service
```

### 从源码构建

```bash
sudo pacman -S --needed base-devel cmake qt6-base qt6-declarative qt6-svg
git clone https://github.com/haoyn231/kde-perfmon.git
cd kde-perfmon
./install.sh
systemctl --user restart plasma-plasmashell.service
```

### 卸载

```bash
rm -rf ~/.local/share/plasma/plasmoids/org.hao.perfmon
systemctl --user restart plasma-plasmashell.service
```

## Installation (KDE Plasma 6)

### Requirements

- KDE Plasma 6 (Qt 6.5+)
- Kirigami (shipped with Plasma)
- This build was produced on Arch Linux / Plasma 6.8 / Qt 6.12

### Install from the release (recommended)

1. Download `kde-perfmon-v1.0.1.tar.gz` and `kde-perfmon-v1.0.1.tar.gz.sha256` from the assets below.
2. Verify and extract the archive into your user Plasma widget directory:
   ```bash
   sha256sum -c kde-perfmon-v1.0.1.tar.gz.sha256
   mkdir -p ~/.local/share/plasma/plasmoids
   tar -xzf kde-perfmon-v1.0.1.tar.gz -C ~/.local/share/plasma/plasmoids
   ```
3. Reload Plasma:
   ```bash
   systemctl --user restart plasma-plasmashell.service
   ```
   Logging out and back in also works.
4. Right-click the panel → **Enter Edit Mode** (or **Add Widgets**) → search for **Performance Monitor** → drag it onto the panel.
5. Click the CPU or memory percentage in the panel to open the process list; click any process row to expand it and use the terminate actions.

### Upgrade from v1.0.0

Extract the new archive over the old installation; the widget configuration is kept. Restart plasmashell to load the new QML and plugin.

```bash
tar -xzf kde-perfmon-v1.0.1.tar.gz -C ~/.local/share/plasma/plasmoids
systemctl --user restart plasma-plasmashell.service
```

### Build from source

```bash
sudo pacman -S --needed base-devel cmake qt6-base qt6-declarative qt6-svg
git clone https://github.com/haoyn231/kde-perfmon.git
cd kde-perfmon
./install.sh
systemctl --user restart plasma-plasmashell.service
```

### Uninstall

```bash
rm -rf ~/.local/share/plasma/plasmoids/org.hao.perfmon
systemctl --user restart plasma-plasmashell.service
```
