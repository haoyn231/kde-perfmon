# kde-perfmon v1.0.0

首个正式版本：一个面向 KDE Plasma 6 的面板性能监视器，参考 DankMaterialShell (DMS) 的交互与 dgop 的采样语义。

The first stable release of a Plasma 6 panel performance monitor, inspired by DankMaterialShell (DMS) and dgop.

## 更新内容 / What's Changed

- 面板预览 CPU 与内存占用，点击后打开进程列表 / Panel preview for CPU and memory, with a click-through process list
- 进程按 CPU 或内存排序，可切换升/降序 / Sort processes by CPU or memory, with ascending/descending toggle
- 顶部系统信息：发行版 logo、发行版名、主机名、用户头像与用户名 / System header with distro logo, distro name, hostname, user avatar and username
- 进程行显示名称、完整命令行、CPU%、RSS、PID / Process rows show name, full command, CPU%, RSS and PID
- 进程列表每秒刷新且保持滚动位置 / The process list refreshes every second while preserving scroll position
- 颜色完全跟随 KDE 明暗主题与强调色 / All colors follow the KDE light/dark scheme and accent color
- 无外部守护进程，直接采样 `/proc` / No daemon; everything is sampled from `/proc`

## 安装教程（KDE Plasma 6）

### 环境要求

- KDE Plasma 6（Qt 6.5+）
- Kirigami（Plasma 自带）
- 本版本在 Arch Linux / Plasma 6.8 / Qt 6.12 上构建

### 从 Release 安装（推荐）

1. 下载本页附件中的 `kde-perfmon-v1.0.0.tar.gz` 与 `kde-perfmon-v1.0.0.tar.gz.sha256`。
2. 校验并解压到当前用户的 Plasma 小程序目录：
   ```bash
   sha256sum -c kde-perfmon-v1.0.0.tar.gz.sha256
   mkdir -p ~/.local/share/plasma/plasmoids
   tar -xzf kde-perfmon-v1.0.0.tar.gz -C ~/.local/share/plasma/plasmoids
   ```
   解压后应存在：
   ```
   ~/.local/share/plasma/plasmoids/org.hao.perfmon/metadata.json
   ~/.local/share/plasma/plasmoids/org.hao.perfmon/contents/lib/Hao/PerfMon/libperfmonplugin.so
   ```
3. 让 Plasma 重新加载插件：
   ```bash
   systemctl --user restart plasma-plasmashell.service
   ```
   也可以注销后重新登录。
4. 右键面板 → **进入编辑模式**（或「添加小组件」）→ 搜索 **性能监视器** / **Performance Monitor** → 拖到面板。
5. 点击面板里的 CPU 百分比或内存百分比，打开进程列表。

### 从源码构建

```bash
sudo pacman -S --needed base-devel cmake qt6-base qt6-declarative qt6-svg
git clone https://github.com/haoyn231/kde-perfmon.git
cd kde-perfmon
./install.sh
systemctl --user restart plasma-plasmashell.service
```

### 卸载

```bash
rm -rf ~/.local/share/plasma/plasmoids/org.hao.perfmon
systemctl --user restart plasma-plasmashell.service
```

## Installation (KDE Plasma 6)

### Requirements

- KDE Plasma 6 (Qt 6.5+)
- Kirigami (shipped with Plasma)
- This build was produced on Arch Linux / Plasma 6.8 / Qt 6.12

### Install from the release (recommended)

1. Download `kde-perfmon-v1.0.0.tar.gz` and `kde-perfmon-v1.0.0.tar.gz.sha256` from the assets below.
2. Verify and extract the archive into your user Plasma widget directory:
   ```bash
   sha256sum -c kde-perfmon-v1.0.0.tar.gz.sha256
   mkdir -p ~/.local/share/plasma/plasmoids
   tar -xzf kde-perfmon-v1.0.0.tar.gz -C ~/.local/share/plasma/plasmoids
   ```
3. Reload Plasma:
   ```bash
   systemctl --user restart plasma-plasmashell.service
   ```
   Logging out and back in also works.
4. Right-click the panel → **Enter Edit Mode** (or **Add Widgets**) → search for **Performance Monitor** → drag it onto the panel.
5. Click the CPU or memory percentage in the panel to open the process list.

### Build from source

```bash
sudo pacman -S --needed base-devel cmake qt6-base qt6-declarative qt6-svg
git clone https://github.com/haoyn231/kde-perfmon.git
cd kde-perfmon
./install.sh
systemctl --user restart plasma-plasmashell.service
```

### Uninstall

```bash
rm -rf ~/.local/share/plasma/plasmoids/org.hao.perfmon
systemctl --user restart plasma-plasmashell.service
```
