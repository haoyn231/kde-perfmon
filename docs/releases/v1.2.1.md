# kde-perfmon v1.2.1

进程列表不再每秒整表重建：改成按 PID 增量对齐（move / insert / remove + 单字段更新），换位的行用一段短位移动画滑过去，切排序时也是滑过去而不是整块跳一下。排序按钮也简化成 amdgpu-top 那种形态——箭头直接长在 `CPU` / `Memory` 按钮里，右边那个独立的圆形方向按钮去掉了。

The process table no longer rebuilds itself every second: rows are now diffed by PID (move / insert / remove plus per-field updates), and rows that change position slide there with a short transition — including when you switch the sort column. The sort control also matches amdgpu-top now: the arrow lives inside the `CPU` / `Memory` chip and the separate round direction button is gone.

## 更新内容 / What's Changed

### 新增 / Added

- **进程行位移动画**：列表顺序变化（数值变化导致换位、进程进出）不再让整张表每秒硬跳，而是把换位的行用 `Kirigami.Units.shortDuration` + `OutCubic` 滑到新位置；展开行、滚动冻结都照旧 / row-move animation: a re-sort slides the rows that actually changed position instead of snapping the whole table once a second.
- **排序方向箭头内置在按钮里**：当前列高亮并在文字右侧显示 `↓` / `↑`，再点当前列反转方向；非激活按钮用透明箭头占住宽度，切换列时整行不会因为多出一个箭头而抖动 / the direction arrow now sits inside the active chip (`CPU ↓`), and the inactive chip reserves the same width so switching columns does not shift the row.
- 预览工具新增 `moves=` / `updates=` / `overlaps=` 三项指标与行几何重叠检测，`resets=` 必须为 0、`overlaps=` 必须为 0 才算正常 / the preview harness now reports `moves=` / `updates=` / `overlaps=` and checks delegate geometry; `resets=0` and `overlaps=0` are the healthy values.

### 变更 / Changed

- `ProcessModel::setProcesses()` 换成 `syncProcesses()`：不再 `beginResetModel`，改为按 PID 对齐后 `beginMoveRows` / insert / remove，并且只对真正变化的字段发 `dataChanged(roles)`。delegate 不再被销毁重建，展开状态与滚动位置都更稳 / the model syncs incrementally instead of resetting, so delegates survive and carry their state.
- **CPU 按界面显示精度（0.1%）排序**：原来比较原始 double，空闲进程亚 0.1% 的采样噪声会让整个尾部每秒互相换位（实测一个窗口 1500–10000 次 move）。分桶比较后同一显示值按 PID 排序，move 降到每秒几十次 / CPU is sorted at the 0.1% resolution the table shows, so the sub-0.1% noise of idle processes no longer reshuffles the whole tail (1500–10000 row moves per window before, tens per tick now).
- 从冻结回到顶部、或重新打开弹窗时，第一帧沿用屏幕上已有的数值，不再先塌成一堆 `0.0%` 再重排；下一秒换成新采样窗口的真实值 / resuming keeps the values that are already on screen for one frame instead of collapsing to 0% and re-sorting.
- `ListView` 关闭 `reuseItems`：它和增量行移动一起用会留下位置没跟上、内容已经换成别的进程的「幽灵行」（实测开着时每帧稳定 18 处行重叠）/ `reuseItems` is disabled — combined with incremental row moves it left ghost rows overlapping each other (18 overlapping pairs per frame with it on).
- 版本号单一来源校验：`cmake` 配置时比对 `CMakeLists.txt` 的 `project(VERSION)` 与 `package/metadata.json` 的 `KPlugin.Version`，不一致直接失败；Release 工作流再校验 tag。/ the CMake and metadata versions are now cross-checked at configure time, and the release workflow validates the tag against both. 修复了「关于」对话框长期显示 1.0.3 的问题（Plasma 在小程序加载时读取元数据，升级后必须重启 plasmashell）。

### 修复 / Fixed

- 滚到列表中部再回到顶部时，偶尔会停在 `contentY=15` 一类的偏移上、`Paused` 标记不消失：增量更新时 ListView 为保持可见行会调整 `contentY`，被误判成「用户滚走了」。现在恢复不再产生整表重排，回顶后 `contentY` 稳定在 0 / returning to the top could occasionally stop a few pixels short and stay stuck in `Paused`; the mass re-sort that caused it is gone, so `contentY` settles at 0.
- 排序按钮从「两个 chip + 一个圆按钮」收敛成 amdgpu-top 的形态，右侧不再多出一个只能翻方向的按钮 / the extra stand-alone direction button is gone.

## 安装教程（KDE Plasma 6）

### 环境要求

- KDE Plasma 6（Qt 6.5+）
- Kirigami（Plasma 自带）
- 本版本在 Arch Linux / Plasma 6.8 / Qt 6.12 上构建

### 从 Release 安装（推荐）

1. 下载本页附件中的 `kde-perfmon-v1.2.1.tar.gz` 与 `kde-perfmon-v1.2.1.tar.gz.sha256`。
2. 校验并解压到当前用户的 Plasma 小程序目录：
   ```bash
   sha256sum -c kde-perfmon-v1.2.1.tar.gz.sha256
   mkdir -p ~/.local/share/plasma/plasmoids
   tar -xzf kde-perfmon-v1.2.1.tar.gz -C ~/.local/share/plasma/plasmoids
   ```
   解压后应存在：
   ```
   ~/.local/share/plasma/plasmoids/org.hao.perfmon/metadata.json
   ~/.local/share/plasma/plasmoids/org.hao.perfmon/contents/lib/Hao/PerfMon/libperfmonplugin.so
   ```
3. 让 Plasma 重新加载插件：
   ```bash
   systemctl --user restart plasma-plasmashell.service
   ```
   也可以注销后重新登录。**这一步不能省**：Plasma 在小程序加载时读取元数据，不重启的话「关于」里还会显示旧版本号。
4. 右键面板 → **进入编辑模式**（或「添加小组件」）→ 搜索 **性能监视器** / **Performance Monitor** → 拖到面板。
5. 点击面板里的 CPU 或内存百分比打开弹窗；再次点击同一处即可关闭。

### 从 v1.1.x 升级

解压覆盖旧目录，保留面板上的小组件配置，然后重启 plasmashell：

```bash
tar -xzf kde-perfmon-v1.2.1.tar.gz -C ~/.local/share/plasma/plasmoids
systemctl --user restart plasma-plasmashell.service
```

> 1.1.x 的排序方向是一个独立的圆形箭头按钮，本版本把它并进了 `CPU` / `Memory` 按钮；面板上的小组件配置不需要改，重启后「关于」里的版本会变成 1.2.1。

### 从源码构建

```bash
sudo pacman -S --needed base-devel cmake qt6-base qt6-declarative qt6-svg
git clone https://github.com/haoyn231/kde-perfmon.git
cd kde-perfmon
./install.sh
systemctl --user restart plasma-plasmashell.service
```

### 卸载

```bash
rm -rf ~/.local/share/plasma/plasmoids/org.hao.perfmon
systemctl --user restart plasma-plasmashell.service
```

## Installation (KDE Plasma 6)

### Requirements

- KDE Plasma 6 (Qt 6.5+)
- Kirigami (shipped with Plasma)
- This build was produced on Arch Linux / Plasma 6.8 / Qt 6.12

### Install from the release (recommended)

1. Download `kde-perfmon-v1.2.1.tar.gz` and `kde-perfmon-v1.2.1.tar.gz.sha256` from the assets below.
2. Verify and extract the archive into your user Plasma widget directory:
   ```bash
   sha256sum -c kde-perfmon-v1.2.1.tar.gz.sha256
   mkdir -p ~/.local/share/plasma/plasmoids
   tar -xzf kde-perfmon-v1.2.1.tar.gz -C ~/.local/share/plasma/plasmoids
   ```
   The extracted tree must contain:
   ```
   ~/.local/share/plasma/plasmoids/org.hao.perfmon/metadata.json
   ~/.local/share/plasma/plasmoids/org.hao.perfmon/contents/lib/Hao/PerfMon/libperfmonplugin.so
   ```
3. Make Plasma reload the plugin:
   ```bash
   systemctl --user restart plasma-plasmashell.service
   ```
   Logging out and back in works too. **Do not skip this**: Plasma reads the metadata when it loads the applet, so the About dialog keeps reporting the old version until the shell restarts.
4. Right-click the panel → **Enter Edit Mode** (or **Add Widgets**) → search for **Performance Monitor** → drag it onto the panel.
5. Click the CPU or memory percentage in the panel to open the popup; click it again to close.

### Upgrade from v1.1.x

Extract over the old directory — the widget configuration on your panel is kept — then restart plasmashell:

```bash
tar -xzf kde-perfmon-v1.2.1.tar.gz -C ~/.local/share/plasma/plasmoids
systemctl --user restart plasma-plasmashell.service
```

> In 1.1.x the sort direction was a separate round arrow button; it now lives inside the `CPU` / `Memory` chips. No panel configuration changes are needed, and the About dialog reports 1.2.1 after the restart.
