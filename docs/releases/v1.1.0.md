# kde-perfmon v1.1.0

弹窗里加了两个和 CPU 直接相关的读数：CPU 卡片头部实时显示**整包功耗**，卡片下方新增一条**每核负载横带**——一根矩形柱对应一个线程，线程数有多少就画多少根。

Two CPU readouts land in the popup: the CPU card now shows the live **package power draw**, and a **per-core load strip** sits right below the cards — one rectangular bar per thread, as many bars as the machine has threads.

## 更新内容 / What's Changed

### 新增 / Added

- **CPU 整包实时功耗**：卡片头部显示当前功耗（如 `36.8 W`），位置与 Memory 卡上的 `Swap` 一致。数据来自内核能量计数器，启动时自动选源：先找 RAPL 的 `/sys/class/powercap/intel-rapl:N`（`name` 以 `package` 开头，MSR 区优先于 mmio 镜像），再退回 hwmon 的 `power1_average`（zenpower）/ `energy1_input`（amd_energy），且只在 CPU 驱动白名单里匹配，不会把 `amdgpu`、`nvme` 的功耗当成 CPU。两者都没有时整块留空，不会显示一个假的 0 W / live package power in the CPU card header, in the same slot as `Swap` on the memory card. The source is resolved at startup: RAPL `powercap` first (MSR-backed zone preferred over the MMIO mirror), then hwmon `power1_average` / `energy1_input` from a CPU-driver whitelist so `amdgpu` / `nvme` cannot be mistaken for the CPU. Hidden instead of faked when no counter exists.
- **每核负载横带**：夹在 CPU / 内存卡片和进程列表之间，一条横带里用矩形柱状图展示每个线程的占用。柱子数量跟着 `/proc/stat` 的 `cpuN` 行走（24 线程就是 24 根，SMT 开关、CPU 热插拔都会自动跟随），右侧显示 `24 threads · peak 87%`，悬停任一根可看到线程编号与该线程百分比 / a per-core load strip between the cards and the process list. The bar count follows the `cpuN` lines of `/proc/stat`, so SMT toggles and CPU hotplug are picked up automatically; the header shows the thread count and the current peak, and hovering a bar reveals the thread index and its percentage.
- **物理核心与线程数区分**：CPU 卡副标题读取 `/proc/cpuinfo` 的 `(physical id, core id)` 拓扑，混合架构机器会显示成 `8 cores · 16 threads`；取不到拓扑时退回线程数 / the CPU card subtitle now separates physical cores from threads using `/proc/cpuinfo` topology, falling back to the thread count.
- 面板悬停气泡也会带上功耗：`CPU 11.0% · 36.8 W · Memory 55.4%` / the panel tooltip now includes the power figure.

### 变更 / Changed

- 柱状图配色跟随主题：低于 70% 用高亮色，70% 以上用 `neutralTextColor`，90% 以上用 `negativeTextColor`，和进程列表的重载配色一致 / bar colors follow the theme: highlight below 70%, `neutralTextColor` from 70%, `negativeTextColor` from 90%, matching the process list.
- 弹窗尺寸从 35 个 gridUnit 提到 38，多出来的高度给横带，进程列表可见行数基本不变 / the popup grows from 35 to 38 gridUnits to make room for the strip.
- 24 根柱子时标签隔一根标一次，避免数字糊成一片 / with 24 threads the index labels are drawn every other bar to stay legible.

### 内部 / Internal

- `PerfBackend` 新增 `cpuPowerWatts` / `cpuPowerAvailable` / `coreUsage` / `physicalCpuCount` 四个属性，能量差分带 `max_energy_range_uj` 回绕处理，功耗过一层 EMA（0.4 / 0.6）平滑 / four new properties; the energy delta handles counter wraparound and the watt figure is EMA-smoothed.
- `/proc/stat` 改成一次读完：聚合行走老解析器，`cpuN` 行走新增的 `parseCoreCpuTimesLine()`。注意 `QFile::atEnd()` 对 `/proc` 文件恒为真（`size()` 是 0），现在用 `readLine()` 读到空为止 / single pass over `/proc/stat`; note that `QFile::atEnd()` always reports true for `/proc` files.
- 每线程百分比变化小于 0.5% 时不发信号，24 根柱子不会每秒重绘 / sub-0.5% changes are not signalled, so 24 bars never repaint for nothing.
- 新增纯函数 `parseCoreCpuTimesLine()`、`cpuBusyPercent()`、`countPhysicalCores()`、`raplPowerWatts()`，单测覆盖 cpuN 解析、拓扑去重（SMT 兄弟不算核）、RAPL 差分 / 回绕 / 复位 / new pure helpers with unit tests for cpuN parsing, topology de-duplication and RAPL deltas including wrap and reset. 测试总数 11 → 16 项。

## 安装教程（KDE Plasma 6）

### 环境要求

- KDE Plasma 6（Qt 6.5+）
- Kirigami（Plasma 自带）
- 本版本在 Arch Linux / Plasma 6.8 / Qt 6.12 上构建

### 从 Release 安装（推荐）

1. 下载本页附件中的 `kde-perfmon-v1.1.0.tar.gz` 与 `kde-perfmon-v1.1.0.tar.gz.sha256`。
2. 校验并解压到当前用户的 Plasma 小程序目录：
   ```bash
   sha256sum -c kde-perfmon-v1.1.0.tar.gz.sha256
   mkdir -p ~/.local/share/plasma/plasmoids
   tar -xzf kde-perfmon-v1.1.0.tar.gz -C ~/.local/share/plasma/plasmoids
   ```
   解压后应存在：
   ```
   ~/.local/share/plasma/plasmoids/org.hao.perfmon/metadata.json
   ~/.local/share/plasma/plasmoids/org.hao.perfmon/contents/lib/Hao/PerfMon/libperfmonplugin.so
   ```
3. 让 Plasma 重新加载插件：
   ```bash
   systemctl --user restart plasma-plasmashell.service
   ```
   也可以注销后重新登录。
4. 右键面板 → **进入编辑模式**（或「添加小组件」）→ 搜索 **性能监视器** / **Performance Monitor** → 拖到面板。
5. 点击面板里的 CPU 或内存百分比打开弹窗；再次点击同一处即可关闭。

### 从 v1.0.x 升级

解压覆盖旧目录，保留面板上的小组件配置，然后重启 plasmashell：

```bash
tar -xzf kde-perfmon-v1.1.0.tar.gz -C ~/.local/share/plasma/plasmoids
systemctl --user restart plasma-plasmashell.service
```

> 功耗读数依赖内核暴露的能量计数器。Intel 平台通常是 `powercap`；AMD 平台需要 `zenpower` 或 `amd_energy`。都读不到时该位置显示为空，其余功能不受影响。

### 从源码构建

```bash
sudo pacman -S --needed base-devel cmake qt6-base qt6-declarative qt6-svg
git clone https://github.com/haoyn231/kde-perfmon.git
cd kde-perfmon
./install.sh
systemctl --user restart plasma-plasmashell.service
```

### 卸载

```bash
rm -rf ~/.local/share/plasma/plasmoids/org.hao.perfmon
systemctl --user restart plasma-plasmashell.service
```

## Installation (KDE Plasma 6)

### Requirements

- KDE Plasma 6 (Qt 6.5+)
- Kirigami (shipped with Plasma)
- This build was produced on Arch Linux / Plasma 6.8 / Qt 6.12

### Install from the release (recommended)

1. Download `kde-perfmon-v1.1.0.tar.gz` and `kde-perfmon-v1.1.0.tar.gz.sha256` from the assets below.
2. Verify and extract the archive into your user Plasma widget directory:
   ```bash
   sha256sum -c kde-perfmon-v1.1.0.tar.gz.sha256
   mkdir -p ~/.local/share/plasma/plasmoids
   tar -xzf kde-perfmon-v1.1.0.tar.gz -C ~/.local/share/plasma/plasmoids
   ```
3. Reload Plasma:
   ```bash
   systemctl --user restart plasma-plasmashell.service
   ```
   Logging out and back in also works.
4. Right-click the panel → **Enter Edit Mode** (or **Add Widgets**) → search for **Performance Monitor** → drag it onto the panel.
5. Click the CPU or memory percentage in the panel to open the popup; click the same spot again to close it.

### Upgrade from v1.0.x

Extract the new archive over the existing installation; the widget configuration is kept. Restart plasmashell afterwards:

```bash
tar -xzf kde-perfmon-v1.1.0.tar.gz -C ~/.local/share/plasma/plasmoids
systemctl --user restart plasma-plasmashell.service
```

> The power readout needs a kernel energy counter: `powercap` on most Intel systems, `zenpower` or `amd_energy` on AMD. When none is readable the figure stays empty and everything else keeps working.

### Build from source

```bash
sudo pacman -S --needed base-devel cmake qt6-base qt6-declarative qt6-svg
git clone https://github.com/haoyn231/kde-perfmon.git
cd kde-perfmon
./install.sh
systemctl --user restart plasma-plasmashell.service
```

### Uninstall

```bash
rm -rf ~/.local/share/plasma/plasmoids/org.hao.perfmon
systemctl --user restart plasma-plasmashell.service
```
