# kde-perfmon v1.2.3

面板上的小组件不再「呼吸」了。之前两个百分比按内容自适应宽度，CPU 从 `9.8%` 涨到 `46.2%` 再多一位数到 `100.0%`，整个图标就跟着一秒一变宽；现在读数位宽是开局就定死的，位数怎么变都只在格子里左右挪。

The panel widget no longer breathes. The two percentages used to size themselves to their text, so the whole icon widened and narrowed every second as `9.8%` turned into `46.2%` and then into `100.0%`; the digit box is now fixed up front, and only the digits move inside it.

## 更新内容 / What's Changed

### 修复 / Fixed

- **面板宽度不再随读数跳动**：数字预留「可能出现的最宽读数」的固定位宽并右对齐（`Layout.preferredWidth` + 两个 `TextMetrics`：`100.0%` 是最长的写法，`88.8%` 是主题字体没兑现 `tnum` 等宽数字时最宽的写法，取两者较大值）。`0.0%` 与 `100.0%` 占同样的格子，图标、间距、整体宽度自始至终不变 / the digit box now reserves the widest possible reading and right-aligns the text, so `0.0%` and `100.0%` occupy the same cell and the widget keeps one width for its whole life. Implementation note: `Layout.preferredWidth` rather than `width` — a layout owns the child's width and would overwrite it on the next relayout (and `qmllint` flags it as `layout-positioning`).
- **点击/悬停区域跟着稳定下来**：宽度不再抖动，也就没有「数字变窄时点到空白」的问题 / the click and hover area is stable too, so there is no more hitting blank space when the number shrinks.

### 变更 / Changed

- CI 的渲染检查会先塞进一个够长的进程列表再跑滚动断言；容器里原本只有两个进程、表格短到根本滚不动，这些断言等于空转 / the render checks now spawn a table long enough to scroll before asserting on scroll behaviour; inside the container there used to be two processes and a table too short to move, so those assertions were vacuous.

## 安装教程（KDE Plasma 6）

### 环境要求

- KDE Plasma 6（Qt 6.5+）
- Kirigami（Plasma 自带）
- 本版本在 Arch Linux / Plasma 6.8.3 / Qt 6.12.0 上构建

### 从 Release 安装（推荐）

1. 下载本页附件中的 `kde-perfmon-v1.2.3.tar.gz` 与 `kde-perfmon-v1.2.3.tar.gz.sha256`。
2. 校验并解压到当前用户的 Plasma 小程序目录：
   ```bash
   sha256sum -c kde-perfmon-v1.2.3.tar.gz.sha256
   mkdir -p ~/.local/share/plasma/plasmoids
   tar -xzf kde-perfmon-v1.2.3.tar.gz -C ~/.local/share/plasma/plasmoids
   ```
   解压后应存在：
   ```
   ~/.local/share/plasma/plasmoids/org.hao.perfmon/metadata.json
   ~/.local/share/plasma/plasmoids/org.hao.perfmon/contents/lib/Hao/PerfMon/libperfmonplugin.so
   ```
3. 让 Plasma 重新加载插件：
   ```bash
   systemctl --user restart plasma-plasmashell.service
   ```
   也可以注销后重新登录。**这一步不能省**：Plasma 在小程序加载时读取元数据，不重启的话「关于」里还会显示旧版本号。
4. 右键面板 → **进入编辑模式**（或「添加小组件」）→ 搜索 **性能监视器** / **Performance Monitor** → 拖到面板。
5. 点击面板里的 CPU 或内存百分比打开弹窗；再次点击同一处即可关闭。

### 从 v1.2.2 升级

解压覆盖旧目录，保留面板上的小组件配置，然后重启 plasmashell：

```bash
tar -xzf kde-perfmon-v1.2.3.tar.gz -C ~/.local/share/plasma/plasmoids
systemctl --user restart plasma-plasmashell.service
```

> 只改了 QML，插件二进制接口没变，面板上的小组件配置也不用动；重启后「关于」里的版本会变成 1.2.3。升级后面板上的图标会略宽一点点——那是给 `100.0%` 预留的位置，之后就固定不动了。

### 从源码构建

```bash
sudo pacman -S --needed base-devel cmake qt6-base qt6-declarative qt6-svg
git clone https://github.com/haoyn231/kde-perfmon.git
cd kde-perfmon
./install.sh
systemctl --user restart plasma-plasmashell.service
```

### 卸载

```bash
rm -rf ~/.local/share/plasma/plasmoids/org.hao.perfmon
systemctl --user restart plasma-plasmashell.service
```

## Installation (KDE Plasma 6)

### Requirements

- KDE Plasma 6 (Qt 6.5+)
- Kirigami (shipped with Plasma)
- This build was produced on Arch Linux / Plasma 6.8.3 / Qt 6.12.0

### Install from the release (recommended)

1. Download `kde-perfmon-v1.2.3.tar.gz` and `kde-perfmon-v1.2.3.tar.gz.sha256` from the assets below.
2. Verify and extract the archive into your user Plasma widget directory:
   ```bash
   sha256sum -c kde-perfmon-v1.2.3.tar.gz.sha256
   mkdir -p ~/.local/share/plasma/plasmoids
   tar -xzf kde-perfmon-v1.2.3.tar.gz -C ~/.local/share/plasma/plasmoids
   ```
   The extracted tree must contain:
   ```
   ~/.local/share/plasma/plasmoids/org.hao.perfmon/metadata.json
   ~/.local/share/plasma/plasmoids/org.hao.perfmon/contents/lib/Hao/PerfMon/libperfmonplugin.so
   ```
3. Make Plasma reload the plugin:
   ```bash
   systemctl --user restart plasma-plasmashell.service
   ```
   Logging out and back in works too. **Do not skip this**: Plasma reads the metadata when it loads the applet, so the About dialog keeps reporting the old version until the shell restarts.
4. Right-click the panel → **Enter Edit Mode** (or **Add Widgets**) → search for **Performance Monitor** → drag it onto the panel.
5. Click the CPU or memory percentage in the panel to open the popup; click it again to close.

### Upgrade from v1.2.2

Extract over the old directory — the widget configuration on your panel is kept — then restart plasmashell:

```bash
tar -xzf kde-perfmon-v1.2.3.tar.gz -C ~/.local/share/plasma/plasmoids
systemctl --user restart plasma-plasmashell.service
```

> Only QML changed; the plugin ABI and your panel configuration are untouched, and the About dialog reports 1.2.3 after the restart. The widget gets a couple of pixels wider once — that is the room reserved for `100.0%`, and it stays put afterwards.
