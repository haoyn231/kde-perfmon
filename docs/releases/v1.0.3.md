# kde-perfmon v1.0.3

进程列表滚动体验重做：只有停在最顶上时才实时刷新，一旦向下滚动就冻结成静态表格，并新增右下角「回到顶部」按钮；同时修复了鼠标滚轮几乎无法滚动列表的问题。

Reworked process list scrolling: the table only refreshes live while pinned to the top, freezes into a still frame as soon as you scroll away, and gains a floating "back to top" button. The mouse wheel now actually scrolls the list.

## 更新内容 / What's Changed

### 修复 / Fixed

- 鼠标滚轮与触控板滚动恢复正常 / Mouse wheel and touchpad scrolling work again。此前 Flickable 内建的滚轮处理只接受第一格事件、之后全部拒绝（实测纯 `ListView` 同样如此），表现为「滚一格就卡住」。现在由 `WheelHandler` 显式驱动滚动：鼠标一格约 45px（2.5 个 gridUnit），触控板按 `pixelDelta` 平滑跟随，指针停在滚动条上也同样可用 / wheel and touchpad scrolling is driven explicitly through a `WheelHandler` instead of relying on Flickable's built-in wheel logic.

### 新增 / Added

- 进程列表只在滚动条位于最顶端时实时刷新；一旦向下滚动（滚轮、拖动滚动条或拖拽列表），表格立即冻结：不重扫 `/proc`、不重排、不重置模型，拖动滚动条不会再被每秒跳动的行打断 / the list only follows the sampler at the top; scrolling away freezes the rows so nothing re-sorts under the pointer
- 冻结时标题旁显示 `• Paused` 状态（带悬停说明），避免把静止表格误认为系统卡住 / a `Paused` marker appears next to the title while frozen
- 右下角圆形「回到顶部」按钮，仅在滚走后出现，点击带回弹动画回到顶部并自动恢复实时刷新 / a round back-to-top button appears in the bottom-right corner when scrolled away
- 冻结状态下终止或强制终止进程时，该行会立即从表格中移除，不必等下一次扫描 / a killed process disappears from the table immediately, even while frozen

### 变更 / Changed

- 点击 `CPU` / `Memory` 排序按钮或方向按钮时，列表回到顶部并恢复实时刷新，新排序结果不会停在任意偏移位置 / changing the sort column returns to the top and resumes live updates
- 列表冻结时，顶部 CPU / 内存卡片仍然每秒更新 / the CPU and memory cards keep updating while the table is frozen

### 内部 / Internal

- `PerfBackend` 新增 `processListPaused` 属性：冻结时 `refresh()` 只采样整机 CPU / 内存，跳过进程扫描；恢复时重置采样基线，避免把暂停期间的 tick 平均成 CPU 百分比 / new `processListPaused` property with a fresh delta window on resume
- `PerfBackend` 新增 `removeProcess(pid)`，`ProcessModel::removePid()` 用 `beginRemoveRows` 就地删除单行 / new `removeProcess(pid)` removing a single row in place
- 单元测试新增 `processListPause`（冻结期零次 `modelReset`、统计仍在更新、恢复立即重扫、重开弹窗清除冻结）与 `removeProcess` / two new unit tests
- 预览工具新增「滚动 → 冻结 → 滚轮 → 回到顶部」场景回放，输出 `LIVE` / `SCROLL` / `WHEEL` / `FROZEN` / `BACK-TO-TOP` / `RESUMED` 检查行 / the preview harness now replays the whole scroll scenario

## 安装教程（KDE Plasma 6）

### 环境要求

- KDE Plasma 6（Qt 6.5+）
- Kirigami（Plasma 自带）
- 本版本在 Arch Linux / Plasma 6.8 / Qt 6.12 上构建

### 从 Release 安装（推荐）

1. 下载本页附件中的 `kde-perfmon-v1.0.3.tar.gz` 与 `kde-perfmon-v1.0.3.tar.gz.sha256`。
2. 校验并解压到当前用户的 Plasma 小程序目录：
   ```bash
   sha256sum -c kde-perfmon-v1.0.3.tar.gz.sha256
   mkdir -p ~/.local/share/plasma/plasmoids
   tar -xzf kde-perfmon-v1.0.3.tar.gz -C ~/.local/share/plasma/plasmoids
   ```
   解压后应存在：
   ```
   ~/.local/share/plasma/plasmoids/org.hao.perfmon/metadata.json
   ~/.local/share/plasma/plasmoids/org.hao.perfmon/contents/lib/Hao/PerfMon/libperfmonplugin.so
   ```
3. 让 Plasma 重新加载插件：
   ```bash
   systemctl --user restart plasma-plasmashell.service
   ```
   也可以注销后重新登录。
4. 右键面板 → **进入编辑模式**（或「添加小组件」）→ 搜索 **性能监视器** / **Performance Monitor** → 拖到面板。
5. 点击面板里的 CPU 或内存百分比打开进程列表；再次点击同一处即可关闭。

### 从 v1.0.0 / v1.0.1 / v1.0.2 升级

解压覆盖旧目录，保留面板上的小组件配置，然后重启 plasmashell：

```bash
tar -xzf kde-perfmon-v1.0.3.tar.gz -C ~/.local/share/plasma/plasmoids
systemctl --user restart plasma-plasmashell.service
```

### 从源码构建

```bash
sudo pacman -S --needed base-devel cmake qt6-base qt6-declarative qt6-svg
git clone https://github.com/haoyn231/kde-perfmon.git
cd kde-perfmon
./install.sh
systemctl --user restart plasma-plasmashell.service
```

### 卸载

```bash
rm -rf ~/.local/share/plasma/plasmoids/org.hao.perfmon
systemctl --user restart plasma-plasmashell.service
```

## Installation (KDE Plasma 6)

### Requirements

- KDE Plasma 6 (Qt 6.5+)
- Kirigami (shipped with Plasma)
- This build was produced on Arch Linux / Plasma 6.8 / Qt 6.12

### Install from the release (recommended)

1. Download `kde-perfmon-v1.0.3.tar.gz` and `kde-perfmon-v1.0.3.tar.gz.sha256` from the assets below.
2. Verify and extract the archive into your user Plasma widget directory:
   ```bash
   sha256sum -c kde-perfmon-v1.0.3.tar.gz.sha256
   mkdir -p ~/.local/share/plasma/plasmoids
   tar -xzf kde-perfmon-v1.0.3.tar.gz -C ~/.local/share/plasma/plasmoids
   ```
3. Reload Plasma:
   ```bash
   systemctl --user restart plasma-plasmashell.service
   ```
   Logging out and back in also works.
4. Right-click the panel → **Enter Edit Mode** (or **Add Widgets**) → search for **Performance Monitor** → drag it onto the panel.
5. Click the CPU or memory percentage in the panel to open the process list; click the same spot again to close it.

### Upgrade from v1.0.0 / v1.0.1 / v1.0.2

Extract the new archive over the existing installation; the widget configuration is kept. Restart plasmashell afterwards:

```bash
tar -xzf kde-perfmon-v1.0.3.tar.gz -C ~/.local/share/plasma/plasmoids
systemctl --user restart plasma-plasmashell.service
```

### Build from source

```bash
sudo pacman -S --needed base-devel cmake qt6-base qt6-declarative qt6-svg
git clone https://github.com/haoyn231/kde-perfmon.git
cd kde-perfmon
./install.sh
systemctl --user restart plasma-plasmashell.service
```

### Uninstall

```bash
rm -rf ~/.local/share/plasma/plasmoids/org.hao.perfmon
systemctl --user restart plasma-plasmashell.service
```
