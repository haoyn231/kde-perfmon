# kde-perfmon v1.2.2

修掉了进程列表的「假冻结」：滚到列表深处再回到顶部、或者切换 CPU/内存与排序方向之后，`Paused` 徽标会赖着不走，拖右侧滚动条到顶也没用，点回来的按钮还会多冲一段再弹回。原因是判断「在不在顶部」用的是 `contentY`，而 `ListView` 滚动时会自己改写 `originY`——列表真正的顶部是 `contentY === originY`，不是 `contentY === 0`。

Fixed the process table's "stuck freeze": after scrolling deep into the list and coming back up — or after switching the CPU/Memory column or the sort direction — the `Paused` badge would refuse to go away, dragging the scrollbar to the top did not help, and the floating button overshot the top and bounced back. The frozen state was derived from `contentY`, but `ListView` rewrites its own `originY` while scrolling: the real top of the list is `contentY === originY`, not `contentY === 0`.

## 更新内容 / What's Changed

### 修复 / Fixed

- **回到顶部就是回到顶部**：位置判断改用 `contentY - originY`。之前滚远之后 `originY` 已经变成几百（甚至负数），回到顶部时 `contentY` 也是几百，被当成「已经滚走了」，于是 `Paused` 永远不消失、拖滚动条到顶也解除不了 / the scroll position is now `contentY - originY`; after a long scroll `originY` is hundreds of pixels (sometimes negative), so "at the top" used to look like "scrolled away" and the badge stayed on no matter what.
- **切排序 / 切方向不再把表冻住**：模型自己搬动 `contentY`（行移动时重定位可见行）不再被当成用户滚动；冻结只由滚轮、滚动条按下、拖动这些真实手势触发 / a re-sort moving `contentY` on its own is no longer mistaken for the reader scrolling; freezing is driven only by the wheel, the scrollbar and drags.
- **`back to top` 不再多冲一段**：动画目标从 `0` 改成 `originY`，落点正好是第一行；结束后再校正一次并立即恢复实时刷新 / the animation now targets `originY` instead of `0`, so it lands on the first row instead of overshooting past the top and bouncing back.
- **活着的表永远钉在顶部**：任何不是读者造成的偏移都会被 `positionViewAtBeginning()` 拉回第一行，排序后看到的就是新顺序的第一名 / a live table is always pinned to its first row, so after a re-sort you see the new number one rather than wherever the view happened to be anchored.

### 变更 / Changed

- 预览工具新增 `PERFMON_PREVIEW_SORT=1` 断言场景：深滚 → 切 CPU/内存/方向 → 回顶 → 再滚 → 拖滚动条回顶，任何一步与预期不符都会以非零退出，CI 每次都会跑（旧版本该用例 3 项失败）/ the preview harness gained an asserting `PERFMON_PREVIEW_SORT=1` scenario (deep scroll → switch column/direction → back to top → scroll again → drag the scrollbar up) that exits non-zero on a mismatch and runs in CI; the old code fails three of its checks.
- `PERFMON_PREVIEW_TRACE=1` 可以打印 16 ms 粒度的 `contentY` / `originY` 轨迹，方便再遇到位置问题时对照 / `PERFMON_PREVIEW_TRACE=1` prints a 16 ms `contentY`/`originY` trace.

## 安装教程（KDE Plasma 6）

### 环境要求

- KDE Plasma 6（Qt 6.5+）
- Kirigami（Plasma 自带）
- 本版本在 Arch Linux / Plasma 6.8 / Qt 6.12 上构建

### 从 Release 安装（推荐）

1. 下载本页附件中的 `kde-perfmon-v1.2.2.tar.gz` 与 `kde-perfmon-v1.2.2.tar.gz.sha256`。
2. 校验并解压到当前用户的 Plasma 小程序目录：
   ```bash
   sha256sum -c kde-perfmon-v1.2.2.tar.gz.sha256
   mkdir -p ~/.local/share/plasma/plasmoids
   tar -xzf kde-perfmon-v1.2.2.tar.gz -C ~/.local/share/plasma/plasmoids
   ```
   解压后应存在：
   ```
   ~/.local/share/plasma/plasmoids/org.hao.perfmon/metadata.json
   ~/.local/share/plasma/plasmoids/org.hao.perfmon/contents/lib/Hao/PerfMon/libperfmonplugin.so
   ```
3. 让 Plasma 重新加载插件：
   ```bash
   systemctl --user restart plasma-plasmashell.service
   ```
   也可以注销后重新登录。**这一步不能省**：Plasma 在小程序加载时读取元数据，不重启的话「关于」里还会显示旧版本号。
4. 右键面板 → **进入编辑模式**（或「添加小组件」）→ 搜索 **性能监视器** / **Performance Monitor** → 拖到面板。
5. 点击面板里的 CPU 或内存百分比打开弹窗；再次点击同一处即可关闭。

### 从 v1.2.1 升级

解压覆盖旧目录，保留面板上的小组件配置，然后重启 plasmashell：

```bash
tar -xzf kde-perfmon-v1.2.2.tar.gz -C ~/.local/share/plasma/plasmoids
systemctl --user restart plasma-plasmashell.service
```

> 只改了 QML 与预览工具，插件二进制接口没变，面板上的小组件配置也不用动；重启后「关于」里的版本会变成 1.2.2。

### 从源码构建

```bash
sudo pacman -S --needed base-devel cmake qt6-base qt6-declarative qt6-svg
git clone https://github.com/haoyn231/kde-perfmon.git
cd kde-perfmon
./install.sh
systemctl --user restart plasma-plasmashell.service
```

### 卸载

```bash
rm -rf ~/.local/share/plasma/plasmoids/org.hao.perfmon
systemctl --user restart plasma-plasmashell.service
```

## Installation (KDE Plasma 6)

### Requirements

- KDE Plasma 6 (Qt 6.5+)
- Kirigami (shipped with Plasma)
- This build was produced on Arch Linux / Plasma 6.8 / Qt 6.12

### Install from the release (recommended)

1. Download `kde-perfmon-v1.2.2.tar.gz` and `kde-perfmon-v1.2.2.tar.gz.sha256` from the assets below.
2. Verify and extract the archive into your user Plasma widget directory:
   ```bash
   sha256sum -c kde-perfmon-v1.2.2.tar.gz.sha256
   mkdir -p ~/.local/share/plasma/plasmoids
   tar -xzf kde-perfmon-v1.2.2.tar.gz -C ~/.local/share/plasma/plasmoids
   ```
   The extracted tree must contain:
   ```
   ~/.local/share/plasma/plasmoids/org.hao.perfmon/metadata.json
   ~/.local/share/plasma/plasmoids/org.hao.perfmon/contents/lib/Hao/PerfMon/libperfmonplugin.so
   ```
3. Make Plasma reload the plugin:
   ```bash
   systemctl --user restart plasma-plasmashell.service
   ```
   Logging out and back in works too. **Do not skip this**: Plasma reads the metadata when it loads the applet, so the About dialog keeps reporting the old version until the shell restarts.
4. Right-click the panel → **Enter Edit Mode** (or **Add Widgets**) → search for **Performance Monitor** → drag it onto the panel.
5. Click the CPU or memory percentage in the panel to open the popup; click it again to close.

### Upgrade from v1.2.1

Extract over the old directory — the widget configuration on your panel is kept — then restart plasmashell:

```bash
tar -xzf kde-perfmon-v1.2.2.tar.gz -C ~/.local/share/plasma/plasmoids
systemctl --user restart plasma-plasmashell.service
```

> Only QML and the preview harness changed; the plugin ABI and your panel configuration are untouched, and the About dialog reports 1.2.2 after the restart.
